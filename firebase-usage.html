How the cloud monitor works

Instrumented apps keep counters locally and upload one compact cumulative snapshot periodically to a Cloudflare Worker. The snapshot is stored in R2, not Firestore, so monitoring does not create Firestore reads or writes. The dashboard reads those snapshots only when opened or refreshed. Google Cloud Monitoring remains the authoritative source for total Firestore usage, including traffic from uninstrumented devices, the Firebase Console and backend services.
