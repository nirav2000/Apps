People

Assign a name to a stable device, auth ID or individual session. Session overrides auth, which overrides device.

Apps

Each browser tab/app session is one session. Visible active time is accumulated rather than simply elapsed clock time.

People & devices

Sessions are grouped by the persistent device ID, not by IP address. Give a device a person/name such as “Nirav”, “Sai” or “Kitchen iPad”; the label is retained centrally and shown across apps.

Security

Passkeys use Face ID, Touch ID, device unlock or your password manager. Sessions expire automatically and can be revoked.

Passkeys

Add more than one so you have a backup. Your password manager can offer to save a passkey when the browser starts registration.

Recovery token

The server stores only a SHA-256 hash in private R2. This password-style form is intentionally compatible with password-manager save prompts.

Active admin sessions

Each is server-side and revocable even if its session token remains cached in a browser.

Coverage

Apps report only after they load https://nirav2000.github.io/Apps/app-monitor.js. The tracker sends an early snapshot, then about every five minutes while used, plus a best-effort update when hidden or closed. It uses Cloudflare R2 and creates no Firebase reads or writes.
